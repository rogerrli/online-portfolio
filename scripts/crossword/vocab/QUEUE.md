# Vetting queue — for Roger

Words the grid search surfaced while Roger was asleep. He asked to be consulted on
each one, so nothing arguable was decided unilaterally:

- **Banned without asking** only where there is no defensible clue for her: non-words,
  bare abbreviations, and names with no route in. Each is listed below with why, and
  each is one line in `banned.txt` to revert.
- **Left in the neither tier** — usable but penalised — for anything arguable. That is
  the no-decision-needed option: the search avoids them unless a slot has no
  alternative, so they only survive into a grid that needs them.
- **Approved** only for ordinary knowledge.

Nothing here is final. Lines can move between tiers and the search re-runs in ~23
minutes per round.
